# SQUIZZZzZ – Live-Quiz-App

Web-App für Live-SQUIZZZzZ-Abende: Spieler antworten im Browser auf dem Smartphone, der Host steuert die Runden, der Beamer zeigt die Show.

Adresse: https://squizzzzz-live.github.io

## Ansichten

| Ansicht | Pfad | Gerät |
|---|---|---|
| Host (Spielleitung) | `/host/` | vor allem Mac/Desktop (Bildschirm, Maus, Tastatur) |
| Spieler | `/` (folgt) | Smartphone, Hochformat |
| Beamer | folgt | Laptop am Beamer/TV, Querformat |

Gemeinsame Bausteine: `css/base.css` (Farben, Schrift), `js/ribbons.js` (bewegte Linien), `js/firebase-config.js`.

**Wichtig:** Dieses Repository ist öffentlich. Es enthält nur App-Code – niemals Fragen, Lösungen, Fragemedien, Spielerdaten oder Zugangsdaten.

Projektplan und Entwicklungsprotokoll liegen im SQUIZZZzZ-Produktionsordner („05 App“).
