Testspiel anlegen

Ein Name pro Zeile. Später kommt die Teilnehmer- und Teamliste als Datei.

Spielcode (optional)

Leer lassen = zufälliger Code. Mit festem Code kannst Du den QR-Code vorab in Deine Screens einbauen. 4–6 Zeichen, Buchstaben und Ziffern 2–9.

So funktioniert's

Nach dem Start erscheint hier ein QR-Code. Die Spieler scannen ihn mit dem Handy, tippen ihren Namen an – und Du siehst live, wer drin ist.
